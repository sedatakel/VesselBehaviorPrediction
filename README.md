# Vessel Behavior Prediction

Exploratory data analysis, preprocessing, model training, and evaluation notebooks for vessel behavior prediction using AIS data.

## Notebooks

- `AIS_DS1_EDA.ipynb`: exploratory data analysis
- `AIS_DS2_Preprocessing_Data_Preparation.ipynb`: preprocessing and data preparation
- `AIS_DS2_Model_Training_Evaluation.ipynb`: model training and evaluation

## Data

The compressed DS1 dataset (`Data/DS1.csv.zip`) and its screenshot are included in the repository. Other raw and generated datasets are excluded from Git because some files exceed GitHub's file-size limit. Place any additional required datasets under `Data/` before running the notebooks.
